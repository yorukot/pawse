# Governance

Breather is currently a maintainer-led open-source project.

## Decision Making

The maintainer is responsible for project direction, releases, security response, moderation, and final review. Decisions prioritize:

1. A safe and reliable Emergency Exit
2. Idempotent cleanup that restores macOS presentation state
3. Correct natural-break and timer behavior
4. Local privacy and accessibility
5. Native macOS quality
6. Maintainable, well-tested implementation

Proposals are evaluated in public issues and pull requests whenever privacy or security does not require a private channel. Constructive disagreement is welcome; final decisions should include a concise technical rationale.

## Contributions

Contributors retain copyright in their work and license accepted contributions under the project’s MIT License. Meaningful recurring contributors may be invited to help triage issues or review changes as the community grows.

## Releases

Only maintainers publish official source tags or binary releases. Public binaries should follow [docs/RELEASING.md](docs/RELEASING.md), including Developer ID signing and notarization.

## Changes to Governance

Governance may evolve as the contributor community grows. Material changes will be documented in this file and discussed publicly before adoption.
