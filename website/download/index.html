Before you install.

Pawse current release is early access. It is ad-hoc signed and has not yet been notarized by Apple, so macOS asks you to approve it manually the first time it opens.

Only continue when the DMG came from this website or the official GitHub release.

Install.

  1. Open the Pawse .dmg from Downloads.
  2. Drag Pawse into Applications, then eject the disk image.
  3. Open Pawse once. macOS will block this early-access build.
  4. Open System Settings → Privacy & Security, click Open Anyway next to Pawse, then confirm with Open. This is needed only once for the build.
