---
title: Troubleshooting
description: Fix common Pawse problems.
---

## Pawse cannot be opened

Follow the [first-launch steps](/docs/install/#first-launch). Only approve an official download.

## Wallpaper does not appear

Choose its folder under **Appearance → Wallpaper Folder**. Reauthorize it if the wallpaper moves.

## Custom image stopped working

Choose the file again under **Appearance → Custom Image**.

## Break returns to Break soon

Input occurred during the grace period. Wait for a fresh idle interval or adjust it under **Break Behavior**.

## Discreet Mode exits immediately

Wait for it to arm before using the keyboard or mouse.

## End Break Early is disabled

Wait for **Minimum Break Time**, or enable **Allow Ending Breaks Early**.

## Language did not change

Quit and reopen Pawse.

## Still stuck?

[Open an issue](https://github.com/yorukot/pawse/issues/new/choose) with the Pawse version, macOS version, and steps to reproduce.
