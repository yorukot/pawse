---
title: Privacy
description: What Pawse stores and reads.
---

Pawse has no account, cloud sync, telemetry, advertising, or networking feature.

## Stored locally

- Preferences in UserDefaults
- Finalized session history in SwiftData
- Read-only access to a selected image or wallpaper folder

## Natural-break detection

Pawse checks aggregate idle duration and input activity while a break is waiting. It does not require Accessibility or Input Monitoring permission.

It does not record keys, pointer positions, apps, windows, websites, screen contents, location, accounts, or device fingerprints.

## Delete data

Clear Analytics from Privacy, remove image or folder access, or delete Pawse's sandbox container after uninstalling.

See the [privacy data contract](https://github.com/yorukot/pawse/blob/main/docs/PRIVACY.md) for contributor details.
