## Start Focus

1. Open the Pawse menu-bar icon.
2. Select **Focus**, then **Start**.
3. Use **Pause**, **Resume**, or **Stop** as needed.

## Start the break

When Focus ends, Pawse shows **Break soon**. Click it or leave the keyboard and pointer idle briefly to begin the scheduled break.

## During the break

- **Discreet Mode:** show the desktop while input stays blocked.
- **End Break Early:** continue after the minimum rest time.
- **Emergency Exit:** end immediately.

Pawse starts the next Focus automatically by default. Choose **Open Pawse** for settings and analytics.
