## Defaults

| Setting | Default |
| --- | --- |
| Focus | 25 minutes |
| Short Break | 30 seconds |
| Long Break | 10 minutes |
| Short Breaks before Long Break | 2 |
| Start breaks automatically | On |
| Start next Focus automatically | On |

## Controls

- **Pause / Resume:** pause Focus.
- **Stop:** interrupt Focus.
- **Skip Focus:** skip to the next break.
- **Skip Next Break:** extend the current Focus by one Focus duration.
- **Switch Mode:** start Focus, Short Break, or Long Break manually.

**Emergency Exit** ends a break immediately. Whether the next Focus starts is controlled by **Continue Cycle After Emergency Exit**.
