---
title: Discreet Mode
description: Keep the desktop visible during a break.
---

Discreet Mode hides the Break screen while the break continues and input remains blocked.

![Discreet Mode settings](/assets/pawse-break-settings.webp)

## Use it

- Choose **Discreet Mode** during a break.
- Any keyboard or mouse activity restores the Break screen.
- Use **End Break Early** or **Emergency Exit** to resume input.

Under **Break Behavior**, you can start every break discreetly and show or hide the yellow menu-bar ring.
