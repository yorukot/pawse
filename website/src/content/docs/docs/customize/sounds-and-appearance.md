## Sounds

| Setting | Default |
| --- | --- |
| Session Start | Submarine |
| Break Ready | None |
| Break Complete | Submarine |
| Volume | 70% |

Use **Preview** to test a sound.

## Break background

- **Desktop Wallpaper:** use each display's wallpaper.
- **Custom Image:** use one local image.
- **Solid Color:** use a dark background.

If a wallpaper cannot be read, authorize its folder under **Wallpaper Folder**.

## Display

- Menu-bar icon: Sleeping Dog (default) or Timer.
- Break countdown: on by default.
- Menu-bar progress ring: on and clockwise by default.
