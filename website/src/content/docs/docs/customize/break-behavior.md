---
title: Break Behavior
description: Configure break entry and controls.
---

Open **Pawse → Break Behavior**.

![Break Behavior settings](/assets/pawse-break-settings.webp)

| Setting | Default | Options |
| --- | --- | --- |
| Wait for Natural Break | On | On / Off |
| Idle Before Break | 2 seconds | 2–30 seconds |
| Break Entry Grace Period | 3 seconds | 1–10 seconds |
| Allow Ending Breaks Early | On | On / Off |
| Minimum Break Time | 30 seconds | 10 seconds–120 minutes |
| Start Breaks in Discreet Mode | Off | On / Off |
| Show Yellow Ring in Discreet Mode | On | On / Off |

End Break Early follows the normal cycle. Discreet Mode shows the desktop but keeps input blocked.
