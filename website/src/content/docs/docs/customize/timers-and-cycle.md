## Timers

| Timer | Default | Range |
| --- | --- | --- |
| Focus | 25 minutes | 10 seconds–180 minutes |
| Short Break | 30 seconds | 10 seconds–60 minutes |
| Long Break | 10 minutes | 10 seconds–120 minutes |

Changes apply to the next session.

## Cycle

- **Enable Long Breaks:** schedule Long Breaks automatically.
- **Short Breaks Before Long Break:** 1–12; default 2.
- **Automatically Start Breaks:** start the scheduled break after Focus.
- **Automatically Start Next Focus:** start Focus after a break.
- **Continue Cycle After Emergency Exit:** start Focus after an Emergency Exit.
- **Reset Break Cycle:** clear the Long Break counter without deleting history.
